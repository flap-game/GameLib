# GameLib Core

Foundation package of GameLib. Every other `com.flapgame.gamelib.*` package depends on it.

Contents (planned for 0.1.x): bootstrap, app lifecycle, consent state, entitlements, analytics contracts,
and the **GameLib Setup** window that installs the other modules step by step.

Install:

```
https://github.com/flap-game/GameLib.git?path=Packages/com.flapgame.gamelib.core#v0.1.0
```
